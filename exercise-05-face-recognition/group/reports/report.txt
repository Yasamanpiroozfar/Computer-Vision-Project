Exercise 5: Face Recognition

4.1 Face Detection, Tracking and Alignment

Settings:
tm_method = cv2.TM_CCOEFF_NORMED
tm_window_size = 25
tm_threshold = 0.70
aligned_image_size = 224

Template matching comparison (mean quality margin):
TM_CCOEFF_NORMED: 0.440563
TM_CCORR_NORMED: 0.055186
TM_SQDIFF_NORMED: 0.124051

TM_CCOEFF_NORMED gave the largest margin, so I used it.

Tracking parameter comparison on Alan_Ball + Nancy_Sinatra:
25 / 0.70 -> 99.21% identification, 108 MTCNN re-detections
50 / 0.80 -> 99.21% identification, 210 MTCNN re-detections

I used 25 / 0.70 because it gave the same identification result with fewer MTCNN re-detections.

Limitations:
45 px motion -> tracking lost, MTCNN re-detection
strong central occlusion -> tracking lost, MTCNN re-detection

4.2 Face Identification and Verification

Settings:
num_neighbours = 3
max_distance = 1.044035
min_prob = 2/3
color/grayscale fusion = 0.5 / 0.5

I tested k = 1, 3, 5, 7. They gave the same closed-set accuracy, so I used k=3.

I also tested different non-zero color/grayscale weights. Several settings gave the same best result, so I used 0.5 / 0.5.
