# ICDAR17 inputs

Place training images in `train/`, test images in `test/`, and the label files
at `icdar17_labels_train.txt` and `icdar17_labels_test.txt`.

Each label line contains the image base name and writer ID. Set `--suffix_train`
and `--suffix_test` to match the image extensions.

Input data and generated caches are excluded from Git.
